## 🌐 Live Preview

**Experience SYNC:** https://sync-social.ai.studio/

SYNC is designed to bring people together through a clean, modern, and interactive social environment. It focuses on conversations, creativity, discovery, and building meaningful digital connections.

## ✨ Features

- **Authentication** – User registration, login, and account management.
- **Social Feed** – Discover and interact with posts.
- **Stories** – Share moments through stories.
- **Create Posts** – Share content with the community.
- **Likes & Comments** – Engage with posts and other users.
- **User Profiles** – Personal profiles, bios, and profile customization.
- **Follow System** – Connect with other people.
- **Real-Time Messaging** – Chat with other users.
- **Notifications** – Stay updated with social activity.
- **Explore** – Discover new content and people.
- **Bookmarks** – Save posts for later.
- **Privacy Settings** – Manage account privacy and preferences.
- **PWA Support** – Installable web application.
- **Android Support** – Android project powered by Capacitor.

## 🎨 Design Philosophy

SYNC follows a premium, minimal, and modern design philosophy.

- Apple Liquid Glass-inspired interface.
- Dark visual experience.
- Smooth animations and transitions.
- Modern glass-style components.
- Responsive user interface.

## 🚀 Run Locally

Want to run SYNC on your computer? Follow these steps.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/ArshNehal/SYNC.git
```

### 2. Open the project

```bash
cd SYNC
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory.

Use `.env.example` as a reference:

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
APP_URL=http://localhost:3000
```

Configure the required Firebase settings using the project's Firebase configuration.

Keep private API keys and credentials out of GitHub.

### 5. Start the development server

```bash
npm run dev
```

### 6. Build for production

```bash
npm run build
```
